[ ENGLISH ]
Welcome to ORMA, a lightweight portable utility to manage your VLC bookmarks.
- Portable application (no installation required).
- Note on Windows SmartScreen: If Windows displays a "PC protected" warning 
  when opening the app, click "More info" and then "Run anyway". This is 
  normal for independent software.
- Freeware: Support development at https://ko-fi.com/angeljulio
